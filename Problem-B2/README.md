# Task B2*: Sum of Divisors (Suma Dzielników)

This repository contains a C solution for the **Task B2\*: Sum of Divisors** algorithmic problem.

## Problem Description

The goal is to calculate the sum of all divisors for multiple given integers efficiently, keeping strict performance and memory constraints in mind.

### Input
- The first line of the input contains an integer $z$ ($1 \le z \le 10^7$), representing the number of queries.
- Each of the following $z$ lines contains a single integer $n$ ($2 \le n \le 8 \cdot 10^6$).

### Output
- For each given number $n$, output the sum of all its divisors.

### Constraints
- **Available memory:** 84 MB
- **Programming language:** C
